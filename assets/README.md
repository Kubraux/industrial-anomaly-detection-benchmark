# Presentation figures

Eight selected figures, each 1200x675 pixels, use Arial typography, fixed margins and 200x200 panel slots. Source image proportions are preserved. Ground-truth and binary-mask panels use nearest-neighbor resizing; score/image panels use Lanczos. Only image rectangles are extracted from pre-existing plots, without changing the displayed field of view, score values or GT geometry. Removed source titles/colorbars are replaced by labels and explicit scale notes; these illustrations are not numerical score readouts.

[SOURCES.csv](figures/SOURCES.csv) records original figure hashes, crop rectangles, output hashes and scale conventions. All source paths are workspace-relative archive identifiers, not bundled links. Original figures and the previous publication trees remain outside GitHub in publication_archive/results_assets_20261023. Original experiment outputs elsewhere in the research workspace are unchanged.

See [results](../results/README.md) for scientific captions and evaluation limits. Examples were selected for interpretation and failure analysis, not randomly sampled performance estimation. No inference or synthetic image generation was performed.
